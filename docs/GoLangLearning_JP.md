## 1. 本ドキュメントについて

このドキュメントは、初学者向けに、
Go言語をどのような順番で学ぶのが良いかをまとめたものです。

他のプログラミング言語の経験がある方を主な対象としていますが、
プログラミング自体が初めての方でも読めるように記載しています。

各ステップには「学ぶこと」と「ここまでできればOK」を記載しています。

「ここまでできればOK」を達成できたら、次のステップへ進んでください。

- Note.
  - 他言語の経験がある方は、ステップ2を流し読みして、
    ステップ3（Goらしい書き方）から重点的に学ぶことを推奨します。

## 2. 学習ステップの全体像

学習は、次の6つのステップで進めます。

| ステップ  | 内容                     | 目安期間 |
| :-------- | :----------------------- | :------- |
| ステップ1 | 環境構築                 | 1日      |
| ステップ2 | 基本文法                 | 1～2週間 |
| ステップ3 | Goらしい書き方           | 1～2週間 |
| ステップ4 | 標準ライブラリーとテスト | 2～4週間 |
| ステップ5 | 並行処理                 | 2～4週間 |
| ステップ6 | 実践                     | 継続的に |

- Note.
  - 目安期間は、1日1～2時間学習した場合のおおよその値です。
  - 並行処理（ステップ5）はGo言語の代表的な機能ですが、
    難易度が高いため、基礎を固めてから学ぶ順番にしています。
    先にステップ6へ進み、必要になってから戻っても問題ありません。

## 3. ステップ1: 環境構築

### 3.1. 学ぶこと

最初に、Go言語を動かせる環境を用意します。

1. 公式サイトからGoをインストールします。
2. ターミナルで`go version`を実行し、バージョンが表示されることを
   確認します。
3. エディターを用意します。
   Visual Studio CodeとGo拡張機能の組み合わせを推奨します。
4. 「Hello, World」を作成し、`go run`で実行します。

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World")
}
```

```bash
go run main.go
```

- Ref. [Download and install][link5]

- Note.
  - インストール前に試したい場合は、ブラウザー上でGoを実行できる
    [Go Playground][link6]が便利です。
  - VS CodeのGo拡張機能を入れると、
    保存時の整形（`gofmt`）が自動で行われます。

### 3.2. ここまでできればOK

- `go version`でバージョンを確認できる。
- 「Hello, World」を`go run`で実行できる。

## 4. ステップ2: 基本文法

### 4.1. 学ぶこと

公式のチュートリアル「A Tour of Go」を、先頭から順番に進めます。

日本語版もあるため、英語が苦手でも取り組めます。

学ぶ内容と順番は、次のとおりです。

1. 変数と型（`var`、`:=`、基本型、ゼロ値）
2. 制御構文（`if`、`for`、`switch`）
3. 関数（複数の戻り値、名前付き戻り値）
4. スライスとマップ
5. 構造体とメソッド
6. ポインター
7. インターフェース

- Ref. [A Tour of Go][link7]

- Ref. [A Tour of Go（日本語版）][link8]

- Note.
  - Goのループは`for`だけです。`while`は存在せず、
    `for 条件 { }`の形式で代用します。
  - Goにはクラスと継承がありません。
    構造体の埋め込みとインターフェースで代用します。
  - 文法の実例を確認したいときは、[Go by Example][link9]が便利です。

### 4.2. ここまでできればOK

- FizzBuzzを書ける。
- スライスとマップの追加、削除、ループ処理を書ける。
- 構造体を定義し、メソッドを追加できる。

## 5. ステップ3: Goらしい書き方

### 5.1. 学ぶこと

文法を覚えたら、Go特有の書き方（イディオム）を学びます。

ここが、他言語の経験者が最もつまずきやすいポイントです。

1. エラー処理
   - Goには例外（try-catch）がありません。
   - エラーは戻り値で受け取り、`if err != nil`で処理します。
2. パッケージとモジュール
   - `go mod init`でモジュールを作成します。
   - ディレクトリー単位でパッケージを分割します。
3. 命名規則と公開範囲
   - 先頭大文字は公開、先頭小文字は非公開です。
4. `gofmt`による整形

エラー処理と命名規則の詳細は、本リポジトリーのルールを参照してください。

- Ref. [Go開発のルール(GoLangRules_JP)](GoLangRules_JP.md)

- Ref. [Go開発のルール詳細解説(GoLangRules_JP_Detail)](GoLangRules_JP_Detail.md)

- Ref. [Effective Go][link1]

- Note.
  - 「エラー処理が冗長」と感じるのは最初だけです。
    エラーの流れがすべてコードに現れるため、
    慣れると障害調査のしやすさを実感できます。

### 5.2. ここまでできればOK

- エラーを返す関数を定義し、呼び出し側で処理できる。
- `fmt.Errorf`と`%w`でエラーに文脈を追加できる。
- `go mod init`でモジュールを作成し、パッケージを分割できる。

## 6. ステップ4: 標準ライブラリーとテスト

### 6.1. 学ぶこと

Goは標準ライブラリーが充実しており、
外部ライブラリーなしで多くの処理を実装できます。

まず、次のパッケージから学ぶことを推奨します。

| パッケージ    | 内容                             |
| :------------ | :------------------------------- |
| fmt           | 文字列の整形、出力               |
| strings       | 文字列操作                       |
| strconv       | 文字列と数値の変換               |
| time          | 日付と時刻                       |
| os            | ファイル操作、環境変数           |
| encoding/json | JSONの読み書き                   |
| net/http      | HTTPクライアントとサーバー       |
| testing       | テスト                           |

テストは、この段階で習慣にします。

`testing`パッケージとテーブル駆動テストの書き方を学び、
書いたコードにテストを付けながら進めます。

- Ref. [Go Standard Library][link10]

- Ref. [詳細解説 6.3. テスト](GoLangRules_JP_Detail.md#63-テスト)

- Note.
  - 標準ライブラリーのソースコードは、Goらしい書き方のお手本です。
    使い方に迷ったら、実装を読んでみることを推奨します。

### 6.2. ここまでできればOK

- JSONファイルを構造体へ読み込み、加工して書き出せる。
- `net/http`でWebページを取得できる。
- テーブル駆動テストを書き、`go test`で実行できる。

## 7. ステップ5: 並行処理

### 7.1. 学ぶこと

並行処理は、Go言語の代表的な機能です。

ただし、設計を誤るとバグの温床になるため、
基礎を固めてから学びます。

1. goroutine（`go`キーワードによる並行実行）
2. チャネル（goroutine間の通信）
3. `select`（複数チャネルの待ち受け）
4. `sync.WaitGroup`（複数goroutineの完了待ち）
5. `context.Context`（キャンセルとタイムアウトの伝播）

goroutineの終了条件とcontextの扱いは、
本リポジトリーのルールも参照してください。

- Ref. [詳細解説 5.9. contextは第一引数で受け取る](GoLangRules_JP_Detail.md#59-contextは第一引数で受け取る)

- Ref. [詳細解説 5.10. goroutineの終了条件を明確にする](GoLangRules_JP_Detail.md#510-goroutineの終了条件を明確にする)

- Note.
  - 「goroutineを起動したら、終了条件を必ず用意する」を
    最初から習慣にすると、goroutineリークを防げます。
  - `go test -race`でデータ競合を検出できます。
    並行処理のテストでは必ず付けることを推奨します。

### 7.2. ここまでできればOK

- 複数のURLへ並行にアクセスし、結果をチャネルで集められる。
- `context.WithTimeout`で処理にタイムアウトを設定できる。
- `go test -race`で並行処理のテストを実行できる。

## 8. ステップ6: 実践

### 8.1. 学ぶこと

小さなツールを自分で作り、公開までの一連の流れを経験します。

題材の例は、次のとおりです。

- CLIツール（`flag`パッケージでオプションを解析）
- Web API（`net/http`でJSONを返すサーバー）
- 定期実行ツール（ファイル監視、バックアップなど）

あわせて、品質を保つ習慣を身につけます。

1. `go vet`と`golangci-lint`による静的解析
2. GitHub ActionsなどのCIでテストと静的解析を自動実行
3. READMEの整備とバージョンタグの付与

- Ref. [詳細解説 6.1. go vet](GoLangRules_JP_Detail.md#61-go-vet)

- Ref. [詳細解説 6.2. staticcheck、golangci-lint](GoLangRules_JP_Detail.md#62-staticcheckgolangci-lint)

- Note.
  - 「自分が毎日使う小さなツール」が最良の題材です。
    改善したい点が自然に見つかり、学習が継続します。

### 8.2. ここまでできればOK

- 自作ツールをGitHubで公開し、`go install`で導入できる。
- CIでテストと静的解析が自動実行される。
